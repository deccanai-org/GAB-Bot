How to have an efficient conversation with the model Tutorial- Creating Model Conversations With Task Guidance.mp4 1. Send the seed prompt exactly as written (copy-paste it). That is Turn 1. 2. Read the whole user intent before your first follow-up, then fulfil all of it as the persona. Make sure no intent, and no part of an intent, is left unattempted. How to use the user intents Each part of the intent has a job: ● Unedited user goal: background only, to help you understand the person. Never paste it to the model. ● Approach: how this person runs the conversation, e.g. “Plan, then build” means get an outline first, reshape it, then have the full thing written. ● Your voice: how this person writes, e.g. “chatty ML engineer thinking out loud, mostly quick one-liners with a casual aside”. Every follow-up should sound like that. Keep the same voice for the whole conversation; switching midway fails the task. ● Goal: what the whole conversation is working towards: the outcome the model should be solving for throughout. ● Turn plan: what to get across in each turn, in order. Each line is an aim, not a script. Write your own message in the persona’s voice, and don’t copy the plan’s wording. Try to stay inside each turn’s word range. ● “If…” lines: raise these only if that situation comes up, e.g. if the AI can write to the wiki with no check, wonder aloud what happens when it writes something wrong. Watch for it in every reply. ● Expected outcome lines: use them to check the model’s answers. Never say them to the model. ● Say when relevant: points the persona would naturally mention, such as a constraint or preference (e.g. “don’t email the CPA”). Bring each one up once,

[page 7]
when it fits the conversation. Don’t repeat it in every turn, and don’t paste the wording. ● Stop when: end the conversation only once everything listed there is in place. While working through the turn plan: ● Cover every ask in a turn. If a turn lists (a) and (b), your message must cover both. Re-read the line before you send. ● React to what the model actually said. Skip a turn only if the model has already covered all of it; if it covered part, ask for the rest. Don’t add turns to fill time. ● Don’t make up details. If the model asks something the intent doesn’t answer, tell it to check your files or go with what it suggests. Don’t add your own details, e.g. your own time zone. ● Cover the same turn plan in Model A and Model B, but write each follow-up against that model’s own reply instead of reusing your Model A prompts. Before you send each follow-up, check one thing: did this message cover every ask in this turn? Etiquettes ● Don’t paste plan wording. The plan says what to do, not what to say, e.g. ‘green-light the build’ → ○ ‘ok this looks right, go ahead and write the full blueprint step by step’ ✅ ; ○ ‘I green-light this’ ❌ . ● Do not nudge the model more than 3 times for each single intent. If it’s still not done after 3 nudges, move on. A model failing is a valid result.

● Only send what the persona would type. Never send tool or status text (‘Allow once’, ‘Continue the original task’) as a prompt, and say ‘my Drive’, not ‘the Drive of this account’. Keeping follow-ups varied Conversations shouldn’t read alike from one task to the next. When writing follow-up prompts: ● Vary length. Include at least one very short turn (under 10 words, e.g. “Too long.” or “Why 3 pm?”) and one longer turn in each conversation. ● Vary the shape of the ask. Not every turn needs to start with “Can you / Could you / Please”. Mix in plain statements (“This reads like a textbook.”), short fragments (“ok, the Grace one, shorter”), a reaction before the ask, or a question back to the model. ● Rephrase recurring checks. Source checks and wrap-ups (“which file does this come from?”, “list what’s done and what’s open”) are expected, but say them differently each time (“show me where that’s from”, “that doesn’t match what I remember”). ● Anchor each turn on the model’s reply . Point to a specific line, number or section from its last response instead of a generic follow-up. Note: the seed prompt is still sent verbatim, and each turn’s aim and word range still apply. These points are only about how you phrase follow-ups.

How to provide the Screen Recording of the conversation ● You need to provide screen recordings with the whole interaction with the model. Start the recording when you ask the first prompt and end it after the last model response. ● ONLY RECORD THE TAB WITH THE CONVERSATION: not the entirety of the screen/including TAB SWITCHES to Cosmo. ● The screen recording will be used to understand the latency in model responses. ● Scroll at a moderate pace - whenever the model produces a long answer and you read through scroll at a moderate pace. ● Quick scrolling directly indicates you are not reading model responses and just pasting/putting up the next prompt. ● Upload the screen recording in the Screen Recording field How to screen record only conversation tab: 🍏 For MacOS users: macOS allows you to record a specific application window rather than the entire desktop using its native capture tools. Using the Built-in Screenshot Toolbar: 1. Press Command + Shift + 5 on your keyboard to open the capture menu. 2. Click the icon for Record Selected Window (the window icon with a pointer) in the on-screen control bar. 3. Click on the specific browser window or app you want to record. (Note: Native Mac recording targets the full application window rather than an individual browser tab, so you may want to separate that specific tab into its own window first). 4. Click Record to start. 5. To stop, click the stop button in the menu bar at the top of your screen or press 6. Command + Control + Escape. 🪟 For Windows users: 1. Open Microsoft Clipchamp or the Clipchamp app on Windows. 2. Select Create a new video and go to the Record & create tab. 3. Choose Screen. 4. When prompted to share your screen, choose Window or Chrome Tab / Edge Tab (depending on your browser), select the exact tab you want, and click Share. 5. Click Stop recording when you are finished and save/export your Video.
