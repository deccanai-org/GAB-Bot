SR0. Why do we need a screen recording? What is it used for?
The recordings are used to understand and evaluate latency in model responses, so the recording must capture the complete model interaction, from the first prompt to the final response, without skipping any steps (not just the end of the conversation). Scroll at a moderate pace: quick scrolling suggests you are not reading the model's responses and are just pasting the next prompt.

SR1. When should you start and stop recording?
- Start recording when you enter your first prompt in the conversation.
- Keep recording through the entire interaction with the model.
- Stop only after the model gives its final response.

SR2. Which screen or tab should be recorded?
- Record ONLY the browser tab that contains the conversation with the model.
- Do NOT record your entire screen, other tabs, other applications, or Cosmo platform navigation.
- If you need to switch to another tab or open Cosmo, make sure that is not captured.
- You may pause the recording when necessary, but resume it before continuing the model interaction.

SR3. What if I need to review a file or document within the conversation?
- If the file or document is part of the conversation and visible in the conversation tab, include it in the recording.
- Make sure the relevant interaction is visible so the complete workflow can be understood.

SR4. Scrolling and reading responses
- Scroll at a moderate, natural pace, especially for long responses.
- Take enough time to read and review the model's answers.
- Avoid rapid scrolling; it can look like responses were not reviewed before the next prompt.

SR5. What if the prompt is lengthy?
- Expand or open the prompt fully before proceeding so the entire prompt is visible and captured clearly.
- Do not leave any part of the prompt hidden or collapsed.

SR6. Breaks and recording continuity
- If you take a break during the task, pause the recording too, and resume it before continuing.
- No part of the actual model interaction may be missed.
- Do NOT upload multiple fragmented recordings. Upload ONE complete video file, from the first prompt to the final model response.

SR7. Where do I upload the recording?
- Upload it in the designated "Screen Recording" field on the task, together with the corresponding JSON files.
- Make sure the uploaded file is complete and covers the entire model interaction.

SR8. Which recording tools can I use?
- Use only tools and applications provided or approved internally for this project.
- Do not use third-party applications, external screen recorders, or unauthorised tools. This is strictly prohibited for data-confidentiality and security reasons, and a violation may result in removal from the project.
- Built-in recorders are fine: Mac: Shift + Command (⌘) + 5. Windows: Windows + Alt + R (Xbox Game Bar), or Windows + Shift + R (Snipping Tool on supported Windows 11 versions).

SR8b. How do I record only the conversation tab?
- Mac: press Command + Shift + 5, click "Record Selected Window" (the window icon) in the control bar, click the browser window, then click Record. Mac records a whole window, not a single tab, so first drag the conversation tab out into its own window. To stop, click the stop button in the menu bar or press Command + Control + Escape.
- Windows: open Microsoft Clipchamp -> "Create a new video" -> "Record & create" tab -> "Screen". When asked to share your screen, choose "Chrome Tab" (or "Edge Tab"), select the exact conversation tab, and click Share. Click "Stop recording" when finished and save/export the video.
- Microsoft Clipchamp is allowed if it is already installed on your desktop. Save recordings locally on your desktop only and upload them to the Screen Recording field. Do not upload or store project recordings on external cloud storage or third-party platforms.

SR9. Are there reference videos?
- Yes: "Model A - Gemini Recording.mp4" and "Model B - Claude Recording.mp4" are attached to the FAQ document. Ask your manager or lead if you cannot find them.

SR10. What if I'm unsure about a recording situation?
Follow these guidelines for every task. If you are unsure about a particular situation, clarify with your lead before proceeding rather than making assumptions.
